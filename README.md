Hướng dẫn sử dụng bản Divinity Original Sin 2 Definitive Edition Việt hóa :

Bước 1: Giải nén và dán đè vào thư mục chính của trò chơi.

Dùng thư mục "Dịch 50" để chơi game với kỹ năng và danh từ giữ nguyên như bản tiếng Anh.
Dùng thư mục "Dịch 100" để chơi game Việt hóa trọn vẹn nhất.
Sử dụng "DOS2_TraCuu_ThuatNgu_Wiki.xlsx" đính kèm theo file zip để tra cứu game khi chơi, lưu ý việc tra cứu sẽ làm lộ cốt truyện, trực tiếp làm giảm trải nghiệm game.
